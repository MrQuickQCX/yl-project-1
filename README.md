# Заметки с форматированием
Приложение для создания и хранения заметок с форматированием. Возможно сохранение заметок как локально, так и в облаке. Также можно будет делиться доступом к заметкам с другими пользователями, будет редактирование прав пользователей: просмотр, изменение. Будут задействованы библиотеки: PyQT, FastAPI и т.д.
